# SafeNET
SafeNET is a browser security extension that detects suspicious links in real time, scores website trust, and warns users before scams or phishing attacks strike.

#Instructions: 
1. Download the files into a folder.
2. Open Google Chrome and go to chrome://extensions.
3. Click on the button reading 'Load Unpacked'.
4. (Optional) Pin the extension for convenience.

Now, whenever you visit a site, just click on the extension and it will equip you with the details needed.
